# Roadmap

## Near Term

- Add request payload validation and clear API error bodies.
- Add controller-level tests for every legacy alias.
- Add generated OpenAPI publishing to the documentation site.
- Add Docker image publishing through GitHub Actions.

## Platform

- Add Helm chart or Kustomize overlays.
- Add readiness and liveness probes in Kubernetes.
- Add container image vulnerability scanning.

## Observability

- Add Micrometer metrics for catalog size, reads, writes, and misses.
- Add structured request logging.
- Add a Grafana dashboard starter.

## Product Depth

- Add import/export of response sets.
- Add named scenarios for test suites.
- Add response version history.
- Add optional authentication for write endpoints.
